# Restaurant Website

### Project Description
A restaurant website developed using Django as a learning project to understand web development and database management.

### Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite (if used in your project)

### Features
- Django administration panel
- Food item management
- Staff member management

### How to Run
1. Clone the repository.
2. Install Django.
3. Run database migrations.
4. Start the Django development server.
